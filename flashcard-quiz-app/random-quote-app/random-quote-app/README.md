# Random Quote Generator

A clean, minimal quote app styled as a tear-off desk calendar page. Shows a
random quote on load, with a "New Quote" button that reveals a different one
each time (with a tearing-page animation), and a Copy button to copy the
quote and author.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This is a standard Vite + React project, so it deploys as-is to Vercel,
Netlify, or GitHub Pages the same way as the flashcard app.
