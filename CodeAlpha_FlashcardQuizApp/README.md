# Flashcard Quiz App

A study flashcard app with 7 topic decks (Web Dev, Geography, Sports, Technology,
Religion, Entertainment, History). Flip cards, navigate with Previous/Next, and
add, edit, or delete cards per deck.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

This is a standard Vite + React project, so it deploys as-is to Vercel, Netlify,
or GitHub Pages — see the main conversation for step-by-step instructions.
